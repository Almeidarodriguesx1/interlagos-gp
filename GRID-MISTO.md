# Grid misto e demonstração de passagem

Na raiz do jogo execute `npm ci` e `npm run dev`. Ao endereço do Vite acrescente `/?car=mcl40&grid=teams&autostart=1&demo=pass`. Recarregue a página para repetir. Clique para liberar o áudio se o navegador pedir interação. Na demonstração, mantenha o McLaren parado para observar as duas passagens. Remova `&demo=pass` para disputar a corrida normal com os modelos disponíveis.

Cada equipe pode receber gravações independentes em `public/audio/teams/<modelo>/`. Os primeiros identificadores são mcl40, sf26 e rb22. O manifesto `public/audio/team-banks.json` é uma lista de identificadores sem extensão. Por exemplo, `["teams/mcl40/cockpit","teams/mcl40/external"]` exige cockpit.wav e external.wav (ou Ogg) no diretório da McLaren. Os dois são loops de regime estável editados para uma referência nominal de 8400 rpm. Registre a procedência e confirme o regime antes de adicionar um take. gear_upshift e gear_downshift são eventos únicos opcionais. Os bancos compartilhados de ambiente e piso continuam independentes. O manifesto entregue está vazio e a reprodução utiliza o áudio experimental anterior até a instalação de gravações identificadas.
